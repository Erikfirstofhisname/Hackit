# Kiro project configuration

This directory contains the repository-scoped Kiro context used for **Loka (Hackit)**. It is committed so collaborators and reviewers can see how Kiro is configured for this project.

## Kiro features represented

- **Steering** in `steering/` supplies persistent product, technology, and architecture guidance.
- **Specs** in `specs/` record requirements, design decisions, and implementation tasks for structured development.

Only intentional, project-safe configuration belongs here. Personal Kiro settings, sessions, caches, logs, credentials, and machine-specific state must not be committed.
